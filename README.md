# Projeto-Redes-de-computadores-2

O grupo escreve um script em Python (usando a biblioteca nativa smtplib) para conectar a um servidor de testes como o Mailtrap ou um servidor SMTP sem autenticação estrita. Enviem um e-mail ao vivo para a turma onde o campo remetente (From:) diz ser, por exemplo, alguma figura famosa para provar que o protocolo original não tem validação de identidade embutida (mostrando a necessidade atual de SPF/DKIM).
